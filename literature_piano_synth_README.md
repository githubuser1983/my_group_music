# Literature-informed Python piano renderer

An independently implemented **reduced modal piano**. Reads MIDI and writes stereo WAV or MP3. It uses neither Pianoteq nor SoundFonts, pretrained models, MIDIUtil, or a sample library. `ffmpeg` is used only to encode MP3.

## Install

```bash
python -m pip install numpy scipy numba mido
# plus FFmpeg installed on PATH for MP3 output
```

## Render

```bash
python literature_piano_synth.py input.mid piano.mp3 \
  --sample-rate 44100 --partials 20 --release 0.16 \
  --soundboard 0.30 --room 0.02 --bitrate 192

# A 25-second trial of the same MIDI:
python literature_piano_synth.py input.mid preview.mp3 --seconds 25

# Dry, clearly articulated piano:
python literature_piano_synth.py input.mid piano_dry.wav --room 0 --release 0.12
```

Rendering is offline, so the first execution may pause while Numba compiles the oscillator; longer compositions require CPU time and RAM proportional to total output duration. The model ignores General MIDI program changes and percussion channel 10; it uses its one piano timbre for pitched notes. It supports tempo changes, note-on/offs, overlapping repeated keys, sustain pedal (CC64), and MIDI channels. When the sustain pedal is held, a note's release is deferred until pedal-up.

## The mathematical model and its scholarly basis

Each pitched note consists of a sum of damped modes:

\[x(t) = \sum_{s=1}^{N_s} \sum_{k=1}^{K} A_{s,k}(v) e^{-t/\tau_{s,k}} \sin(2\pi f_{s,k}t),\]

with a short rise and an additional damper decay after the MIDI note-off. The partial frequency relation is

\[f_{s,k} = k f_{1,s}\sqrt{\frac{1+B k^2}{1+B}}.\]

The second formula uses the **first observed partial** as `f1`, not the ideal flexible-string fundamental. `B` is a stiffness/inharmonicity coefficient. The source for modal strings, frequency-dependent losses and inharmonicity is Bank, Zambon and Fontana (2010); a modern differentiable spectral piano interpretation appears in Simionato, Fasciani and Holm (2024). The latter is the motivation for keeping the modes and envelopes explicit, not for using its trained weights (none are used).

- **Hammer / velocity:** effective hammer position suppresses modes near strike-position nodes; a velocity-dependent spectral envelope approximates the contact-time effect. This is a simplified excitation proxy, **not** a nonlinear felt-contact solver.
- **Unison strings:** one string at low notes, two in tenor and three in treble, with small relative detunings and different decays. They create beats, but no complete physical bridge-mediated bidirectional string coupling.
- **Soundboard:** a small parallel bank of damped second-order filters approximates selected soundboard modes/radiation. Its frequencies are **illustrative choices**, not a measured grand piano, finite-element solution or a physical bridge admittance.
- **Pedal/damper:** MIDI CC64 extends the note before the model applies a faster release decay. There is no cross-note sympathetic string coupling from lifted dampers.
- **Room:** optional quiet early reflections (`--room`, `0` disables); no heavy ambient reverb.
- **Output:** mix and normalize to 90% full scale, then WAV/MP3. The signal is generated by formulas, not by replaying recordings.

There is no claim of equal fidelity to Modartt's commercial Pianoteq. Full 3D hammer–string–soundboard coupling requires a substantially richer model, measured parameters and acoustic calibration; see Xie (2024), Elie et al. (2022), and Jenei-Kulcsár and Fiala (2023). Values for B, damping, amplitudes, and soundboard filters in this script are designed to produce a recognizably piano-like sound without measured instrument data, not presented as empirically fitted numbers.

3. Elie, B., Cotté, B., & Boutillon, X. (2022). *Physically-based sound synthesis software for Computer-Aided-Design of piano soundboards*. Acta Acustica 6, 30. DOI: [10.1051/aacus/2022024](https://doi.org/10.1051/aacus/2022024).

DOI: [10.17743/jaes.2026.0283](https://doi.org/10.17743/jaes.2026.0283). An overview of an **alternative** synthesis family; this program uses modal synthesis, not digital waveguides.
